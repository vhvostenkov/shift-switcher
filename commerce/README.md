# Платёжное ядро: только локальная подготовка

Это не работающий сервер и не подключённый эквайринг. Модуль ledger не делает банковских
запросов; платежи не принимает, чеки не выдаёт, письма не отправляет.
Отдельный `tbank.py` умеет Init/GetState только с DEMO-терминалом. Модульные тесты используют фикстуры. Отдельный DEMO API-прогон
20.10.2026 подтвердил Init, оплату официальной тестовой картой и GetState CONFIRMED,
затем полный Cancel и GetState REFUNDED. Webhook, чек и активация не проверены.
Тесты используют синтетические подписанные события и fake GetState.

Реализованы отдельный SQLite ledger, привязка платежа к заказу, проверка Token,
обязательное независимое GetState, проверка суммы, идемпотентное состояние,
запрет повторного открытия возвращённой лицензии, 2 устройства и Ed25519
подпись сертификата активации. Ключи создаются только временно в тестах.
Идентификатор устройства — SHA-256 случайного ID установки, не аппаратный ID.

Сертификат действует 30 дней. Возврат блокирует новые активации и обновления
сертификатов, но уже выданный офлайн-сертификат может оставаться действительным
до окончания этого срока. Это ограничение нужно отразить в будущих условиях.
Частичный возврат приостанавливает лицензию до ручной проверки; политику
возвратов и восстановления нужно утвердить до продаж.

Перед production ещё нужны HTTP API с ограничениями частоты/размера, реальный
Init/GetState transport, постоянные ключи в защищённом хранилище, RF primary DB,
шифрование/резервное копирование, заказ/checkout с защищённым хранением ключа,
чеки, доставка/восстановление покупки и интеграция проверки сертификата в Mac app.
Ранние 100 лицензий по 299 ₽ пока не реализованы: цена ядра фиксирована 499 ₽,
чтобы незавершённая логика резерва не продавала ограниченное предложение сверх лимита.

```sh
python3 -m unittest commerce.test_ledger -v
```

Официальные источники контракта:
- https://developer.tbank.ru/eacq/intro/developer/token
- https://developer.tbank.ru/eacq/intro/developer/notification

## Безопасный ввод DEMO владельцем

В локальном терминале из каталога репозитория:

```sh
python3 -m commerce.configure_demo
```

Оба значения вводятся скрыто, сохраняются вне Git в приватном каталоге
пользователя с правами 0700/0600. Рабочие ключи скрипт не принимает.
Не пересылайте пароли в чат. Сохранение конфигурации само по себе не
отправляет запрос банку и не подтверждает работу эквайринга.

## DEMO API probe

`python3 -m commerce.probe_demo` создаёт один тестовый заказ 499 ₽ без чека
и не выдаёт лицензию. Требует локальной DEMO-конфигурации и отдельного CA bundle
`~/.config/shift-switcher-commerce/tbank-ca.pem`. Его источник:
https://status.tbank-online.com/certificates/ → Russian_Trusted_CA.pem.
Системное хранилище не меняется, проверка TLS и имени хоста обязательна.
Запись платежа хранится только в приватном каталоге 0600. Нельзя запускать
этот probe как публичный checkout: callback URL пока заглушки.

Разрешённый новый хост платёжной формы `pay.tbank-online.com` получен от
аутентифицированного Init API банка 20.10.2026. Остальные произвольные домены
и нестандартные порты отклоняются.
