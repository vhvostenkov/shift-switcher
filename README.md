# Shift Switcher

Независимая утилита для macOS: двойной Shift исправляет раскладку выделенного
текста, а без выделения — последнее слово перед курсором. Дополнительно можно
включить автоматическое исправление RU ↔ EN после пробела.

**[Страница приложения](https://vhvost.com/shift-switcher/)** ·
**[Скачать beta 0.2.0](https://github.com/vhvostenkov/shift-switcher/releases/tag/v0.2.0)**

## Возможности

- Двойной Shift для выделения и последнего слова.
- Нативное окно настроек, управление из строки меню.
- Отдельные переключатели автоисправления и паузы.
- Проверка разрешений Accessibility и Input Monitoring.
- Отмена последнего исправления, пока текст поля не изменился.
- Пропуск парольных полей и Secure Input.
- Исключения автоматики для терминалов, редакторов кода и менеджеров паролей.

Приложение не записывает историю ввода и не отправляет набираемый текст на
сервер. Последнее исправление временно хранится в памяти для отмены.

## Установка

Нужен Mac с Apple silicon и macOS 13 или новее.

1. Скачайте ZIP из Releases, распакуйте и перенесите приложение в «Программы».
2. Откройте Shift Switcher и выдайте ему «Универсальный доступ» и «Мониторинг ввода».
3. Перезапустите приложение после выдачи разрешений.
4. Попробуйте в TextEdit: `ghbdtn` + двойной Shift → `привет`.

Это beta с локальной ad-hoc подписью, без Developer ID и нотариализации Apple.
macOS может не разрешить первый запуск автоматически. Подробная инструкция
есть [на странице приложения](https://vhvost.com/shift-switcher/#install) и в ZIP.

## Сборка

Требуются Xcode Command Line Tools со Swift. Сборка для ARM64:

```sh
./build.sh
open 'build/Shift Switcher.app'
```

Скрипт запускает 33 проверки ядра и личных правил, собирает приложение и подписывает его локально.
После пересборки macOS может потребовать повторного добавления приложения
в оба раздела разрешений.

## Проверки и границы

Версия 0.2.0: 17 проверок ядра, визуальная проверка нативного окна и переключателей,
проверка распакованного архива и подписи. Нативный TextEdit-прогон 5/5 выполнен
для предыдущей версии 0.1.0 с синтетическими CGEvent; он не является подтверждением
физической клавиатуры или совместимости со всеми приложениями новой сборки.

Accessibility должен предоставлять значение, диапазон выделения и возможность
замены текста. Неподдерживаемые поля пропускаются. Системные словари `ru`/`en`
не гарантируют корректного распознавания имён и технических терминов.

Для явного нативного прогона предусмотрен аргумент `--native-acceptance`.
Он создаёт отдельный тестовый файл, открывает TextEdit и отправляет события
только при фокусе в этом тестовом документе. Нужны оба разрешения macOS.

## Структура

- `Sources/` — Swift/AppKit/SwiftUI.
- `Tests/` — проверки преобразования и распознавания двойного Shift.
- `Assets/` — иконка и её генератор.
- `site/` — статическая страница для `vhvost.com/shift-switcher/`.
- `scripts/package-release.py` — упаковка готового приложения и SHA-256.

Код и словари стороннего Lang Switcher не включены. Проект не связан с его разработчиками.
Автоматические GitHub Actions workflows в репозитории не настроены.

## Коммерческий кандидат — отдельная ветка

План и фактические критерии выпуска: [COMMERCIAL_RELEASE.md](docs/COMMERCIAL_RELEASE.md).
Ветка `codex/commercial-launch` содержит кандидат 0.3.0 с режимами по приложениям,
личным словарём, управлением автозапуском и защитой от смены фокуса перед заменой.
Отдельное платёжное ядро и DEMO transport находятся в `commerce/` и не подключены
к публичному сайту. Продажи не открыты, лицензирование в приложении ещё не включено.

Изолированная сборка, не заменяющая обычный bundle ID:

```sh
APP_NAME='Shift Switcher Candidate' CANDIDATE_BUILD=1 ./build.sh
```

Проверки кандидата: 33 проверки Swift, 28 проверок платёжного ядра и DEMO transport;
нажатия кнопок и сохранение личных правил проверены в нативном интерфейсе.
Регистрация реального автозапуска, матрица совместимости и реальный банковский
DEMO цикл этими проверками не подтверждены.
