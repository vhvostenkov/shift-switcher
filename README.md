# Shift Switcher

Независимая утилита для Mac и Windows: двойной Shift исправляет раскладку выделенного
текста, а без выделения — последнее слово перед курсором. Дополнительно можно
включить автоматическое исправление RU ↔ EN после пробела.

**[Страница приложения](https://vhvost.com/shift-switcher/)** ·
**[Скачать для Windows](https://vhvost.com/shift-switcher/downloads/Shift-Switcher-Windows.zip)** ·
**[Скачать для Mac](https://vhvost.com/shift-switcher/downloads/Shift-Switcher-Mac.zip)**

Ссылки ведут на последнюю проверенную сборку — номер версии выбирать не нужно.
Ручное исправление и отмена бесплатны; пробный Pro на 14 дней добавляет автоматику.
Пользователям Winston и Radar доступен [бесплатный Pro на два компьютера](https://vhvost.com/shift-switcher/benefits.html), включая бесплатные тарифы. Один ключ подходит для Mac и Windows в любой комбинации.
Лицензия подходит для Windows+Mac, двух Windows или двух Mac. Продажи закрыты до
настоящей контрольной покупки, чека и возврата.

## Возможности

- Двойной Shift для выделения и последнего слова.
- Нативное окно настроек, значок в строке меню Mac или трее Windows.
- Отдельные переключатели автоисправления и паузы.
- Проверка разрешений Accessibility и Input Monitoring.
- Отмена последнего исправления, пока текст поля не изменился.
- Пропуск парольных полей и Secure Input.
- Исключения автоматики для терминалов, редакторов кода и менеджеров паролей.

Приложение не записывает историю ввода и не отправляет набираемый текст на
сервер. Последнее исправление временно хранится в памяти для отмены.

## Установка

### Windows

Нужна Windows 10/11 x64 (Intel/AMD). [Инструкция](https://vhvost.com/shift-switcher/windows.html).
Распакуйте ZIP в постоянную папку, откройте `ShiftSwitcher.exe` и включите нужные
переключатели автоисправления и автозапуска. .NET Runtime уже включён в приложение.
Для Pro импортируйте скачанный файл лицензии на странице «Лицензия».

### Mac

Нужен Mac с Apple silicon и macOS 13 или новее.

1. Скачайте ZIP по ссылке «Скачать для Mac» выше, распакуйте и перенесите приложение в «Программы».
2. Откройте Shift Switcher и выдайте ему «Универсальный доступ» и «Мониторинг ввода».
3. Перезапустите приложение после выдачи разрешений.
4. Попробуйте в TextEdit: `ghbdtn` + двойной Shift → `привет`.

Кандидат выпуска имеет локальную ad-hoc подпись, без Developer ID и нотариализации Apple.
macOS может не разрешить первый запуск автоматически. Подробная инструкция
есть [на странице приложения](https://vhvost.com/shift-switcher/#install) и в ZIP.

## Сборка

Требуются Xcode Command Line Tools со Swift. Сборка для ARM64:

```sh
./build.sh
open 'build/Shift Switcher.app'
```

Скрипт запускает 169 проверок ядра, лицензии, личных правил и настроек клавиш, собирает приложение и подписывает его локально.
Сборщик отказывается перезаписывать запущенную копию: сначала завершите её или выберите другой `APP_NAME`.
После пересборки macOS может потребовать повторного добавления приложения
в оба раздела разрешений.

## Проверки и границы

Историческая версия 0.2.0: 17 проверок ядра, визуальная проверка нативного окна и переключателей,
проверка распакованного архива и подписи. Нативный TextEdit-прогон 5/5 выполнен
для предыдущей версии 0.1.0 с синтетическими CGEvent; он не является подтверждением
физической клавиатуры или совместимости со всеми приложениями новой сборки.

На Mac Accessibility должен предоставлять значение, диапазон выделения и возможность
замены текста. Неподдерживаемые поля пропускаются. Системные словари `ru`/`en`
не гарантируют корректного распознавания имён и технических терминов.

Для явного нативного прогона предусмотрен аргумент `--native-acceptance`.
Он создаёт отдельный тестовый файл, открывает TextEdit и отправляет события
только при фокусе в этом тестовом документе. Нужны оба разрешения macOS.

## Исправление смешанного слова в 0.3.1

`копbz` исправляется в `копия`, `helдщ` — в `hello`: уже правильная часть слова сохраняется. Двойной Shift повторно отменяет точную последнюю замену в том же неизменённом поле и положении курсора. Для автоматики направление проверки словаря определяется последней набранной раскладкой.

Оригинальный Lang Switcher и Shift Switcher не следует запускать одновременно: оба перехватывают клавиши. Перед проверкой используйте только один переключатель. Новые сценарии нативного теста проверяют смешанные слова, пробел, отмену и сохранение предыдущих `mesh wifi`.

Проверка 0.3.1: 83 проверки ядра и 20/20 сценариев CGEvent в отдельном TextEdit через обычный LaunchServices. Проверены смешанное слово, сохранение предыдущих слов, исправление после пробела и точная отмена. [Отчёт](docs/evidence/mixed-word-031-native-2026-10-22.json). Физический ввод и другие программы на этой сборке не проверялись.

## Контекст фразы в 0.3.2

Автоматика проверяет до 12 завершённых слов текущей строки, сохраняет правильные английские слова и повторяет пропущенную из-за быстрого набора проверку после короткой паузы. Соседние однозначные слова помогают распознать одиночные буквы: `привет как b` → `привет как и`. Запятая/точка в конце слова сохраняется. Текущий незавершённый токен, адреса, числа и личные исключения пропускаются. После явной отмены уже восстановленный фрагмент повторно не исправляется, пока его префикс не изменился.

Это локальные словарные правила языкового контекста, без смысловой модели и отправки текста в сеть. Неизвестные обоим словарям имена и термины автоматически не угадываются. Enter не перехватывается и отправка сообщения не задерживается.

## Ручной выбор и отдельный символ в 0.3.3

⌃⌥. исправляет один символ слева от курсора; выделение по двойному Shift исправляется как раньше. Для знаков без букв направление определяется текущей клавиатурой. Добавлены знаки цифрового ряда @/" и #/№; обычные цифры совпадают в обеих раскладках. После ручной замены или явной отмены восстановленный префикс защищён от автоматического исправления. ⌘Z защищает точное восстановление в редакторах с собственной историей отмены. Маркировки с цифрами/дефисом не исправляются по частям без выделения; автоматика сохраняет прописные аббревиатуры.

В поддерживаемых веб-редакторах выбран один путь ввода Unicode, без последовательных AX-записи и резервного ввода. Переключение языка проверяет результат macOS; при неудаче приложение сообщает об этом. Одновременный оригинальный Lang Switcher блокирует исправление в нашей программе и показывает предупреждение о конфликте.

## Проверка после паузы и словарь названий в 0.3.4

Автоматическая замена ждёт 300 мс без новых клавиш. Это уменьшает риск изменения выделения во время продолжения ввода. Завершённые слова проверяются после паузы; незавершённое слово не меняется. В «Личные правила → Слова → Знакомые слова» можно добавить название. Явное ручное исправление неизвестного слова также запоминается локально и удаляется из того же списка. «Не исправлять» остаётся отдельным списком. Русское «о» перед английским названием распознаётся по предыдущему русскому слову.

Бесплатная лицензия владельца выдаётся отдельным подписанным файлом для одной установки, максимум на год. DEMO и LIVE используют разные доверенные ключи; выдача LIVE требует явного операторского `--allow-live-owner`. Она не создаёт платёжный заказ и не восстанавливает возвращённую лицензию. Обычные сертификаты по-прежнему ограничены 31 днём. Длительный офлайн-сертификат владельца не проверяет отзыв до истечения срока; это не формат лицензий покупателей. Закрытый конфиг подписи и .sslicense хранятся вне Git.

Быстрый ввод в поисковом поле Chrome привязывается к самому полю, даже если браузер ещё не согласовал текст и курсор в Accessibility. Замена ждёт согласованных данных после паузы; смена поля отменяет попытку. Монитор клавиатуры не ждёт ответы браузера. Проверки быстрого набора, точной отмены и смены RU/EN: [отчёт 20.11.2026](docs/evidence/search-034-2026-11-20.md).
