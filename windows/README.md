# Shift Switcher для Windows

Нативный кандидат коммерческого выпуска для Windows 10/11 x64 (Intel/AMD).
[Скачать последнюю проверенную сборку](https://vhvost.com/shift-switcher/downloads/Shift-Switcher-Windows.zip) ·
[Установка](https://vhvost.com/shift-switcher/windows.html).

Ручное исправление и отмена бесплатны. Автоматика включена в пробный Pro на 14 дней
и в активную лицензию. Пользователи Radar, включая бесплатные тарифы, получают
[Pro на два устройства](https://vhvost.com/shift-switcher/benefits.html); Winston подключаем.
Подходят Windows + Mac, два Windows или два Mac. Реальные продажи пока закрыты
до контрольной покупки, настоящего чека и возврата. ARM64 можно собрать из исходников,
но опубликованная и принятая на ПК сборка — x64.

## Интерфейс

Четыре страницы: «Обзор», «Личный словарь», «Лицензия» и «О приложении».
На «Обзоре» — состояние, раскладка, пауза, автоматика, автозапуск и клавиши.
Светлые карточки, фиолетовый акцент, прокрутка при небольшой высоте; в трее — RU/EN
и состояние автоматики/паузы. Ранний коммерческий интерфейс проверен при 125%
в обычном и минимальном размере; исправление HTTP-активации его не меняло.

## Исправление текста

В прежней проверенной сборке `13f23a47` найден дефект: после автоисправления курсор
оставался перед пробелом, следующее слово могло склеиться с первым. Исправление
`09ff8596` сохраняет хвост до курсора в одном пакете замены. На отдельном Windows-ПК
прошли 60/60 проверок ядра и повторный сценарий в textarea/search: `hello `,
курсор 6/6 → `hello world `, курсор 12/12. Отмена, смена RU/EN и четыре сценария
повторного запуска тоже прошли. [Отчёт новой сборки](../docs/evidence/windows-caret-fixed-native-2026-11-25.json)
отделён от прежних результатов. Ещё 12 синтетических сценариев в textarea/search
прошли по тексту, отмене и дополнительному пробелу. Фактические интервалы ввода
составили 11.38–94.68 мс; целевые 10/25 мс не подтверждены ни в одной строке.
[Полная матрица](../docs/evidence/windows-rapid-native-2026-11-25.json) сохраняет
функциональный результат отдельно от непройденного временного допуска.

## Реализовано в коде

- Двойной Shift: выделенный фрагмент либо последнее слово, включая смешанное `копbz`.
- Повторный двойной Shift и Ctrl+Alt+Z: точная отмена при неизменённом тексте поля.
- Ctrl+Alt+. — один предыдущий символ; обычные цифры совпадают в двух раскладках.
- Переключение между установленными русской и английской (США) раскладками, с проверкой результата.
- Автоматика после пробела и паузы; локальный контекст завершённых слов и личный словарь.
- Защита явно отменённого/ручного исправления от повторной автоматики после пробела.
- Трей с RU/EN и состоянием, пауза, настройки, необязательный автозапуск при входе.
- Повторный запуск того же EXE открывает настройки работающей копии; второй
  фоновый запуск не показывает окно. На Windows проверены скрытое/свёрнутое
  окно, повторный фоновой запуск и первый фоновой старт с последующим открытием.
- Отдельный поток перехвата; обращения к UI Automation не блокируют callback клавиатуры.
- Замена выделения через Unicode SendInput. В коде нет Clipboard, Ctrl+C/V или резервной вставки.
- Проверка исходного поля, полного значения, выделения и нового физического ввода перед записью.

Автоматика изначально выключена. Для неё нужны оба словаря Windows `ru-RU` и `en-US`.
Без них она недоступна, ручная замена остаётся. Терминалы и редакторы кода исключены
из автоматики; парольные поля и менеджеры паролей не исправляются.

Работа требует редактируемого поля с UI Automation TextPattern. Неподдерживаемые
поля пропускаются. Приложение работает без повышения прав и не обходит UIPI/UAC.
Ручная замена ограничена 256 единицами UTF-16; большой текст и несовпадающие
диапазоны провайдера не вставляются. Закрытие настроек оставляет программу в трее;
для завершения выберите «Выйти».

## Сборка

Нужен .NET 10 SDK. Публикация включает .NET Desktop Runtime 10.0.15;
на компьютере пользователя устанавливать .NET отдельно не требуется.
Версия runtime закреплена по [метаданным Microsoft](https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json)
от 25.11.2026. Глобальный SDK и настройки других проектов не меняются.

```powershell
./windows/build.ps1 -Runtime win-x64
# Для Windows ARM64:
./windows/build.ps1 -Runtime win-arm64
```

С macOS/Linux:

```sh
dotnet run --project windows/ShiftSwitcher.Checks -c Release
dotnet publish windows/ShiftSwitcher.Windows -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:EnableCompressionInSingleFile=true -o release/windows/win-x64
```

Приложение: `release/windows/<архитектура>/ShiftSwitcher.exe`.
Распакуйте в постоянную папку перед включением автозапуска. Сборка пока без Authenticode;
системные предупреждения безопасности не отключаются сборщиком.

Настройки и знакомые слова хранятся в `%LOCALAPPDATA%\VHVost\ShiftSwitcher\settings.json`.
История набора не сохраняется. Автозапуск записывается только при включении пользователем,
в собственное значение `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\VHVost.ShiftSwitcher`.

После полного закрытия и запуска штатным ярлыком Pro, автоматика и автозапуск ON,
один процесс, прежние настройки и HKCU Run. Старые EXE и owner-DPAPI сохранены приватно.

[Реальное скачивание нового ZIP](../docs/evidence/downloads-service-gift-browser-2026-11-26.json).

Клавиатурная логика не менялась с ранее проверенных сборок. Исторические

автозапуска может показывать OFF при неизменённом Run; штатный ярлык показывает ON.

## Коммерческий кандидат

Кандидат добавляет страницу «Лицензия», 14 дней пробного Pro и активацию общего
продукта `shift-switcher-pro-v1`. Ручное исправление и отмена остаются бесплатными;
автоматика требует действующего пробного периода или Pro. Сохранённое желание
включить автоматику не теряется после окончания пробного периода.

Сборка по умолчанию принимает только LIVE-сертификаты. Тестовая среда задаётся
явно при сборке через `-p:LicenseEnvironment=DEMO`; DEMO не активирует LIVE.
Ключ и сертификат хранятся атомарно под защитой DPAPI текущего пользователя без
запроса пароля. Проверка подписи Ed25519 работает локально; оплаченный сертификат
продлевается через HTTPS и действует до 30 дней без соединения. Бесплатная
лицензия владельца выдаётся отдельно, привязана к установке и имеет срок действия.

Переносимые проверки: `dotnet run --project windows/ShiftSwitcher.LicensingChecks -c Release`.
Реальную DPAPI проверяет только Windows: `dotnet run --project windows/ShiftSwitcher.LicensingNativeChecks -c Release`.
Эти проверки и установка выполнены на отдельном ПК; квитанция приведена выше.
Платёж, настоящий чек НПД и возврат ещё не проверены в LIVE.
