# Нативная приёмка Windows Preview

Полная приёмка пока не выполнена. На физическом ПК Windows 10 x64 прошли 45/45
проверок ядра, 22 проверки Блокнота и 15 проверок Chrome (0 ошибок, password
недопроверен). Фактическая смена RU/EN подтверждена в Chrome. См. отчёты
[Блокнота](../docs/evidence/windows-physical-notepad-2026-11-25.json) и
[Chrome](../docs/evidence/windows-physical-chrome-2026-11-25.json).
Сборка и консольные проверки ядра не заменяют этот прогон.
Проверять в отдельных новых тестовых документах; чужие/рабочие поля не использовать.
Сначала завершить другой переключатель раскладки, если он работает.

Записать SHA-256 EXE, Windows/архитектуру, версию Chrome и доступность RU/EN.
Все проверки ниже нужны в Блокноте и двух полях из `Tests/fixtures/compatibility.html`
(поиск Chrome и textarea). Пароль проверяется только в отдельном тестовом password-поле.
HTTPS-копия тестовой страницы: https://vhvost.com/shift-switcher/compatibility-windows-20261125.html .

| Сценарий | Ожидается |
|---|---|
| Выделить `ghbdtn`, двойной Shift | `привет`, активная RU |
| Повторить двойной Shift | точное `ghbdtn`, активная EN |
| `mesh wifi копbz`, без выделения, двойной Shift | только последнее слово → `mesh wifi копия` |
| `вф`, двойной Shift | ровно один `da`, активная EN |
| Отменить `da`, добавить пробел | `вф ` сохраняется, активная RU |
| Включить автоматику: `ghbdtn` + пробел | `привет `, активная RU |
| `руддщ` + пробел | `hello `, активная EN |
| `руддщ` + пробел, дождаться автоматики, затем набрать `world` + пробел | после первой замены курсор после пробела, итог `hello world ` без склейки |
| Исправить слово перед двумя пробелами / незавершённым следующим словом | весь хвост и исходная позиция курсора сохраняются |
| Быстро `bkb vbh `, 10/25 мс между клавишами | `или мир `, без добавленных/потерянных букв |
| Отмена быстрого исправления | исходная фраза, пробелы и исходная раскладка |
| Ещё один пробел после отмены | исходный текст не исправляется повторно |
| Быстро `руддщ цщкдв ` и `руддщ руддщ ` | `hello world ` и `hello hello `, затем точная отмена и RU |
| Добавить `voron` в знакомые: `отзывы j мщкщт 400 ` | `отзывы о voron 400 ` |
| `hello world`, `DA-10`, URL, email | автоматика сохраняет правильный текст и маркировки |
| `тестю`, Ctrl+Alt+. | только последний символ → `тест.`, активная EN; точная отмена |
| Emoji/составной символ перед выделением | точная замена; либо безопасный отказ неподдерживаемого провайдера |
| Изменить текст/поле после исправления, вызвать отмену | отказ без изменения нового текста |
| Переместить фокус во время ожидания | другое поле не изменяется |
| Новый ввод во время чтения/выделения | устаревшая попытка не вставляет текст |
| Пароль, readonly, повышенный процесс | пропуск/отказ без запроса повышения прав |
| Занятый Ctrl+Alt+Z или Ctrl+Alt+. | конфликт виден; чужая регистрация не подменяется |
| До/после проверки скопировать контрольный текст и изображение | все форматы буфера обмена сохранены |
| Закрыть настройки | процесс/трей продолжают работу |
| Повторно запустить тот же EXE после закрытия настроек | настройки работающей копии открываются, процесс остаётся один |
| Повторно запустить тот же EXE с `--background` | новая копия не остаётся, настройки не открываются |
| Включить автозапуск, выйти/войти в Windows | одна копия приложения, проверка после настоящего входа |

Синтетический SendInput-драйвер, если используется, должен быть отдельно согласован
для Windows, привязан к тестовому процессу/окну/полю и прекращать ввод при смене фокуса.
Приложение игнорирует только свой marker `0x535357`, чтобы внешний удалённый ввод
и средства доступности могли проходить hook. Внешний SendInput/ввод CUA остаётся
синтетической проверкой и не доказывает работу физической клавиатуры.

Для каждого поля сохранять результат отдельно с одним SHA-256. Прерванный прогон,
отсутствие ошибок сборки или успешный запуск процесса не считать полной приёмкой.
