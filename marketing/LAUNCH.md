# Подготовка продвижения Shift Switcher

## Статус

Продажи закрыты до рабочей активации, чеков, актуальных ключей и контрольной покупки. Рекламный бюджет 0 ₽. Ничьи аккаунты и каналы не используются без выбора владельца. Рекламные публикации не отправлены.

## Позиционирование

Независимый переключатель раскладки для Mac. Двойной Shift исправляет выделение или последнее слово. Ручное исправление бесплатно; Pro добавляет автоматику с пробным периодом 14 дней. Текст остаётся на Mac. Установка требует разрешений macOS; сборка без нотариализации Apple.

## Черновик короткой публикации

Набрали ghbdtn вместо «привет»? Сделал Shift Switcher для Mac: выделяешь текст и нажимаешь Shift дважды. Без выделения исправляется последнее слово. Ручной режим бесплатный, текст никуда не отправляется. Есть пробная автоматика RU↔EN. Apple silicon, macOS 13+. Сборка пока без нотариализации Apple — инструкция по установке на странице.

Попробовать: https://vhvost.com/shift-switcher/?utm_source=owner_channel&utm_medium=post&utm_campaign=launch

1. 0–4: ошибочная раскладка `ghbdtn vbh` в TextEdit.
2. 4–8: выделение → двойной Shift → `привет мир`.
3. 8–12: последнее слово без выделения.
4. 12–16: окно приложения, настройки и локальная обработка.
5. 16–20: адрес страницы, доступные Mac и честное предупреждение об установке.

Использовать только тестовый документ; не показывать личные переписки и данные банка. Не выдавать смонтированную демонстрацию за физическую приёмку.
