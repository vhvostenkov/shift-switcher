# Обновления Shift Switcher

Первая версия с обновлениями устанавливается поверх существующей копии. Сохраните
путь к `Shift Switcher.app` или `ShiftSwitcher.exe`: к этому пути привязан автозапуск.
Брать установочные ZIP можно по прежним ссылкам на странице приложения.

Проверка запускается примерно через полминуты после старта и повторяется каждые
шесть часов, пока приложение работает. Пункт «Проверить обновления…» доступен
в меню значка на обеих платформах. Там же можно отключить автоматические обновления.

- **Mac.** Приложение скачивает проверенный пакет в фоне и показывает наличие
  обновления в меню. Выберите «Обновить и перезапустить», когда удобно. macOS может
  попросить повторно разрешить «Универсальный доступ» и «Мониторинг ввода», поскольку
  сборки подписаны локально. Если папка недоступна для записи, используйте ZIP.
- **Windows.** После проверки приложение устанавливает обновление, когда окно
  настроек закрыто, активация лицензии завершена и на ПК нет ввода три минуты.
  Можно запустить установку сразу из меню. Для папки с правами только на чтение
  используйте ZIP.

Обновление заменяет приложение по прежнему пути. Настройки, словарь и лицензия
остаются в штатном профиле пользователя. Запись автозапуска Windows сохраняется,
а на Mac приложение проверяет прежнюю регистрацию после запуска. Система может
потребовать подтверждение для записи автозапуска.

## Публикация

Стабильная версия X.Y.Z совпадает с версией в Mac Info.plist и Windows EXE.
Соберите обе платформы и проверьте обновление в обе стороны: успешная замена
с тестовым профилем и восстановление после неудачного запуска новой сборки.

Опубликуйте оба проверенных архива в GitHub Releases под тегом `vX.Y.Z` с именами
`Shift-Switcher-Mac.zip` и `Shift-Switcher-Windows.zip`. После публикации скачайте
их как гость и сверьте контрольные суммы. Только затем создайте подписанный список:

```sh
python3 scripts/sign-update.py X.Y.Z Shift-Switcher-Mac.zip Shift-Switcher-Windows.zip update.json
```

Скрипту нужен OpenSSL 3 и приватный ключ Ed25519 в
`~/.config/shift-switcher-updates/signing.pem` с правами 0600. Храните его отдельно
от репозитория и сервера публикации. Приложения содержат только публичный ключ.
Если резервная копия ключа потребуется при смене машины, храните её зашифрованной.

Опубликуйте `update.json` в `/shift-switcher/downloads/` вместе с обычным манифестом
скачивания после проверки публичных ZIP. Клиенты проверяют подпись списка, номер
версии, размер и SHA-256 ZIP до распаковки. Список обновлений не ссылается на
кандидаты, а ссылки на ZIP определяются из подписанного номера версии.
