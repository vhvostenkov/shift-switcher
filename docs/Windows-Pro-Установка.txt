Shift Switcher для Windows

Скачать последнюю сборку: https://vhvost.com/shift-switcher/

1. Извлеките ZIP в постоянную папку, например Документы → Shift Switcher.
2. Откройте ShiftSwitcher.exe. Отдельная установка .NET не нужна.
3. На странице «Обзор» включите автоисправление и автозапуск, если они нужны.
4. Наберите ghbdtn в отдельном документе и дважды нажмите Shift: привет.

Без выделения исправляется последнее слово; с выделением — выбранный текст.
Повторный двойной Shift отменяет исправление при неизменённом поле.
Ctrl+Alt+Z — отмена. Ctrl+Alt+. — один символ слева от курсора.
Иконка в трее показывает RU/EN. Закрытие настроек оставляет приложение в фоне.
Для завершения выберите «Выйти» в меню значка.

Ручное исправление и отмена доступны бесплатно. Пробный Pro действует 14 дней;
Pro включает автоматику после пробела. Состояние, активация и импорт файла
находятся на странице «Лицензия». Коммерческие продажи открываются только после
проверки кассы; текущий статус доступен на сайте. Не оплачивайте сторонние ключи.
Одна купленная лицензия рассчитана на два компьютера Mac / Windows.
Для её продления требуется соединение с vhvost.com хотя бы раз в 30 дней.
Лицензия хранится под защитой Windows DPAPI текущего пользователя.

Автоматика требует русских и английских языковых словарей Windows. Парольные
и неподдерживаемые поля пропускаются; терминалы и редакторы кода исключены
из автоматики. Текст обрабатывается локально. Замена не использует буфер обмена.
Совместимость зависит от доступности текста через Windows UI Automation.

Сборка без подписи Authenticode. Сверяйте источник и контрольную сумму.
Защиту Windows отключать не нужно.
