# Стабильный выпуск 1.0.0 — 28.11.2026

Mac и Windows выпущены одним стабильным релизом. GitHub Releases помечен Latest;
постоянные ссылки на сайте и в README не требуют выбора версии.
Платные продажи остаются закрытыми. Выпуск приложения не включает запуск оплаты.

## Состав выпуска

В стабильный канал перенесены точные приложения кандидата `v1.0.0-rc.3`, без пересборки.
В ZIP для Mac обновлена только инструкция: убрано прежнее обозначение кандидата.
Файлы внутри `.app`, их права и подпись сохранены; Windows ZIP не переупаковывался. Внутренняя версия
Windows EXE остаётся `1.0.0-rc.2`; она идентифицирует проверенную сборку, а статус
стабильного выпуска задаётся тегом `v1.0.0` и манифестом. Новых исправлений кода
между кандидатом и стабильным выпуском нет.

## Проверки

- Mac: 169 переносимых проверок; нативный TextEdit 11/11 на точном бинарнике выпуска.
  Проверены первое слово после пробела, двойной Shift с выделением и без,
  сохранение соседнего слова, отдельный знак, точная отмена и фактическая смена RU/EN.
- Windows: 60 core, 59 licensing и 7 нативных DPAPI проверок. На точном EXE выпуска
  дополнительно проверены автоматика в Chrome, немедленная отмена и смена EN → RU → EN.
- На обеих платформах проверены Pro и онлайн-продление обычной сервисной лицензии.
  Синтетический ввод не изменил счётчик буфера обмена.
- 28.11 архивы кандидата скачаны через реальные кнопки сайта и из GitHub; ZIP и приложения
  внутри совпали с проверенными файлами. У стабильного Mac ZIP дополнительно
  проверено, что изменена только инструкция. Переносимые проверки повторены перед релизом.

Сводная квитанция: [stable-1.0.0-2026-11-28.json](evidence/stable-1.0.0-2026-11-28.json).
Предыдущие результаты сохраняются со своими хешами в `docs/evidence`.

## Совместимость

Mac: Apple silicon, macOS 13+. Windows: Windows 10/11 x64, нативный прогон — Windows 10.
Intel Mac и Windows ARM не поддерживаются этим выпуском. Работа конкретного поля
зависит от Accessibility/UI Automation. Проверки синтетические: физическая клавиатура,
точный темп 25 мс и все приложения не подтверждены. Автозапуск настроен и проверен
после перезапуска приложения; фактический выход и повторный вход в ОС не проверялись.
Расширенный план Windows остаётся в `windows/ACCEPTANCE.md`.

Mac подписан локально без нотариализации Apple; Windows — без Authenticode.
Рекомендации по первому запуску и разрешениям опубликованы на сайте.

## Следующий выпуск

Новый ZIP публикуется только вместе с хешем вложенного приложения, исходным коммитом
и результатами проверок этого бинарника. При изменении приложения прежний нативный
прогон не считается прогоном новой сборки. Имя скачиваемого ZIP остаётся постоянным.
Кандидаты сохраняют prerelease-статус; стабильный выпуск получает отдельный тег и Latest.
