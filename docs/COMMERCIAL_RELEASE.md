# Коммерческий выпуск Shift Switcher

Состояние 20.10.2026: коммерческий кандидат, продажи закрыты. Владелец — Виктор;
реализация и проверка — Codex в этом чате.

## Принятые решения

- Не покупать Apple Developer Program. Приложение имеет ad-hoc подпись, без нотариализации.
- Общая касса продуктов VHVost: https://vhvost.com/pay/.
- Один серверный каталог продуктов, общие заказы, банковские уведомления, чеки и возвраты.
- Shift Switcher — первый товар. Проект цены: Pro 1.x за 499 ₽ разово на два Mac.
  Ограниченная акция 299 ₽ не реализована и покупателям не обещается.
- Pro: автоматика RU↔EN, полный пробный режим 14 дней. Ручное исправление и отмена — Free.
- Сертификат лицензии обновляется онлайн раз в 30 дней; срок прямо указан до оплаты.
- Заказы и лицензии — отдельная база в РФ. Существующие базы/подписки Winston не менялись.

## Реализовано и проверено

- Настройки режимов приложений, личные исключения, автозапуск, клавиши и отмена.
- Контроль фокуса/поля/значения перед заменой. Защищённые поля и Secure Input пропускаются.
- Ed25519 лицензия, случайный ID установки, разделение DEMO/LIVE и лимит устройств.
- Приватное локальное хранилище 0700/0600; штатный запуск не вызывает диалоги Связки ключей.
- Общая касса и каталог: сервер определяет цену/продукт, сохраняет версии условий и согласие.
- Подпись банковского webhook + независимый GetState, идемпотентность и отзыв после возврата.
- Отдельный systemd-пользователь, частный сетевой вход, шифрованные проверяемые backup.
- Нативная активация DEMO нового магазина и сохранение после перезапуска.
- Реальный DEMO сценарий нового магазина: Init → SBP test → CONFIRMED → настоящий webhook
  → файл лицензии → активация Mac → повторный запуск → банковский REFUNDED.
- 60 тестов commerce на Mac и RF-хосте, код сервиса 22e0c13.
  Это фикстуры; банковское E2E описано отдельно.
- Swift/нативные проверки и точные fingerprint находятся в `docs/evidence/`.
  Прямой запуск: 14/14 в TextEdit, Safari, Chrome и Notes (56/56), 64 Swift-проверки.
  Повтор обычного запуска через LaunchServices ожидает разблокировки Mac.
  Резервная замена в браузерах ограничена 256 UTF-16, буфер обмена не используется.
