- Индикатор RU/EN и режима; резервный Unicode-ввод для Codex без буфера обмена.
- Исправление слов от двух букв (`yf` → «на», `yt` → «не», `lf` → «да») и клавиш
  пунктуации в словах (`ghj,tkf` → «пробела»), с проверкой по словарям.
- После пробела ограниченное ожидание значения и курсора AX. Новый ввод или смена
  поля отменяют попытку. Поля паролей и Secure Input по-прежнему исключены.
- Один бинарник `ed7bc0142715c99be933bb0c90c2cb49414583755104e271a518f573d7f201d9`:
  74 Swift checks, 14/14 нативных сценариев TextEdit и ещё 6/6 проверок коротких слов,
  отмены и сохранения правильных английских слов. Буфер обмена не изменился.
- Проверены подпись распакованного архива, нормальный запуск установленной копии
  `/Users/max/Applications/Shift Switcher Candidate.app`, оба разрешения, включённая
  автоматика, выключенная пауза. Автозапуск включён и сохранён после перезапуска
  приложения; фактическая перезагрузка Mac не проверялась.
- Закрытие окна настроек оставляет процесс работающим. Установленная копия отделена
  от сборочной папки: новые тестовые сборки не перезаписывают её.
- Доказательства: `docs/evidence/preview-4-native-2026-10-21.json`.
  Ранние прогоны, прерванные потерей фокуса, не считаются успешными.
- Владелец подтвердил исправление после пробела в Codex в промежуточной сборке.
  Финальный бинарник автоматически проверен только в TextEdit. Инструмент запрещает
  агенту управлять полем Codex. Исторические 56/56 ниже относятся к Preview 3.

## Решения владельца

- Apple Developer Program не покупать: ad-hoc подпись без нотариализации.
- Общая касса VHVost: https://vhvost.com/pay/. Первый товар — Shift Switcher Pro 1.x.
- Плановая цена 499 ₽ разово на два Mac; Pro trial 14 дней.
- Ручное исправление и отмена — Free. Сертификат Pro требует обновления онлайн раз в 30 дней.
- НПД, настоящие чеки через «Мой налог». Платная онлайн-касса не подключалась.
- Заказы/лицензии — отдельная база в РФ. Winston и его подписки не мигрировались.

- Один финальный бинарник e73f1813543eeb74f113fa06f1b5d3241ee897a2db5f5529cac563f8070ca9f5:

  две отмены, правильные слова, альтернативный хоткей, длинный текст с emoji, отказ
  отмены после изменения поля. Оригинальный Lang Switcher перед финальным прогоном закрыт.

  максимум 256 UTF-16, без буфера обмена.

- DEMO нового магазина: Init → SBP test → CONFIRMED → настоящий webhook → файл лицензии
