# Коммерческий выпуск Shift Switcher

Состояние 20.10.2026: приложение проверено как preview, реальные продажи закрыты.

## Текущая правка после preview (не опубликована)

- Разрешены автоматические преобразования клавиш пунктуации в буквы другой
  раскладки: `ghj,tkf` → «пробела», `chf,jnfkj` → «сработало». Проверка по
  словарям и ограничение коротких слов сохранены.
- Индикатор строки меню показывает текущий язык ввода, автоматику/ручной режим,
  паузу и отсутствие разрешений; меню настроек и отмены остаётся доступным.
- 71 Swift check, сборка и проверка подписи прошли. После перепривязки обоих
  разрешений новый бинарник `532180f8c2730e24c54ee1f224acf5aa0077f92184cfd8864d050991a17d7d77`
  прошёл 14/14 CGEvent-проверок TextEdit. Отдельно `ghj,tkf` → «пробела» и
  `yf;fnbb` → «нажатии» исправились после пробела и отменились; счётчик изменений
  буфера обмена остался прежним. Приложение перезапущено без тестовых аргументов.
  Доказательства: `docs/evidence/autocorrection-punctuation-2026-10-20.json`.
  Результаты 56/56 ниже относятся к опубликованному preview, не к этой правке.
- Владелец вручную подтвердил исправление `ghbdtn` после пробела в текущем поле
  чата Codex. Это отдельное пользовательское подтверждение: инструмент управления
  запрещает доступ к приложению, автоматический прогон этого поля не проводился.

## Решения владельца

- Apple Developer Program не покупать: ad-hoc подпись без нотариализации.
- Общая касса VHVost: https://vhvost.com/pay/. Первый товар — Shift Switcher Pro 1.x.
- Плановая цена 499 ₽ разово на два Mac; Pro trial 14 дней.
- Ручное исправление и отмена — Free. Сертификат Pro требует обновления онлайн раз в 30 дней.
- НПД, настоящие чеки через «Мой налог». Платная онлайн-касса не подключалась.
- Заказы/лицензии — отдельная база в РФ. Winston и его подписки не мигрировались.

## Проверенные результаты

- 64 Swift checks, 61 commerce test на Mac и РФ-хосте.
- Один финальный бинарник e73f1813543eeb74f113fa06f1b5d3241ee897a2db5f5529cac563f8070ca9f5:
  по 14/14 в TextEdit, Safari, Chrome и Notes, суммарно 56/56. Запуск через LaunchServices,
  ввод синтетическим CGEvent только в отдельных тестовых документах.
- Проверены выделение/последнее слово/обратная замена, автоматика RU↔EN после пробела,
  две отмены, правильные слова, альтернативный хоткей, длинный текст с emoji, отказ
  отмены после изменения поля. Оригинальный Lang Switcher перед финальным прогоном закрыт.
- Физическая клавиатура, Telegram и Office не проверены. Резервный ввод в браузерах —
  максимум 256 UTF-16, без буфера обмена.
- Нет интерактивных запросов Keychain в штатном хранении лицензии; приватный файл 0600.
- DEMO нового магазина: Init → SBP test → CONFIRMED → настоящий webhook → файл лицензии
  → нативная активация → повторный запуск → банковский REFUNDED. Настоящих денег не было.
- Серверный каталог/цена/продукт, идемпотентность, подпись webhook + GetState, отзыв лицензии,
  разделение баз DEMO/LIVE, версии согласий, проверяемые шифрованные backup.
- Общая очередь писем лицензий/чеков, без автоматического повтора неопределённой отправки.
  По разрешению владельца настроен существующий Gmail (закрытый файл 0600 вне Git).
  Одно тестовое письмо с РФ-хоста найдено во Входящих Gmail: 1a158dbfcb342cae.
  Это проверка транспорта; реальная покупка/чек письмом ещё не доставлялись.
