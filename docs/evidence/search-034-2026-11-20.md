## Change

Capture the focused field identity on space without requiring a simultaneously valid
AX value and caret. After 300 ms idle, require two matching value/caret reads, bounded
to 150 ms additional settling. New keys, clicks, selection changes or another field
cancel the attempt. Browser AX work runs outside the event-tap callback; a dedicated
run loop delivers copied events, retaining original timestamps for double Shift.

Unicode chunks wait for both text and caret, tolerate temporarily unavailable AX data,
and always post a paired key-down/key-up. No clipboard write or paste fallback was added.

An untouched last edit can be undone even if Chrome moves its caret during input-source
handoff. The expected field and full value must still match. An intervening physical
key or click disables this exception; the ordinary selection-based rule then applies.
