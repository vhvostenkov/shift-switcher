# Бесплатный Pro пользователям сервисов

Решение владельца 26.11.2026: пользователи Winston и Radar получают Shift Switcher
Pro 1.x бесплатно, включая пользователей бесплатных тарифов. Одна лицензия — две
установки в любой комбинации Mac / Windows. Для остальных цена остаётся 499 ₽.

Выдача привязана к зарегистрированной учётной записи сервиса. Пробный период
отдельный; бесплатная сервисная лицензия не является продлением trial и не создаёт
банковский заказ, фиктивный CONFIRMED, возврат или почтовую отправку.
Один аккаунт одного сервиса повторно получает тот же ключ. Разные аккаунты/сервисы
не объединяются по имени или непроверенному email.

## Контракт подтверждения

1. На `vhvost.com/shift-switcher/benefits.html` пользователь принимает опубликованные
   условия. `POST /pay/api/benefit/start` принимает `provider` (`winston` / `radar`) и
   `consent` с версиями условий/политики. Сервер создаёт случайный state на 10 минут,
   хранит только его хеш и устанавливает HttpOnly/Secure/SameSite cookie `ss_benefit`.
2. Браузер открывает настроенный HTTPS-адрес сервиса
   `/api/product-benefits/shift-switcher?state=<64 lowercase hex>`.
   Сервис проверяет свою сессию и членство в аккаунте. Тариф не проверяется.
3. Сервис подписывает Ed25519 строку `sb1.<base64url-json>` и возвращает браузер на
   **фиксированный** `https://vhvost.com/shift-switcher/benefits.html#ticket=<token>`.
   Фрагмент сразу убирается из адреса и не попадает в HTTP-запрос/Referer.
4. `POST /pay/api/benefit/claim` проверяет подпись настроенного issuer, state/cookie,
   срок, продукт, среду и одноразовый jti. Создаёт или находит отдельный benefit grant.
   Пароль и сессия сервиса остаются в сервисе; в кассу попадает непрозрачный псевдоним.

Подписанный JSON:

```json
{
  "schema": 1,
  "issuer": "winston",
  "audience": "shift-switcher-benefit",
  "product": "shift-switcher-pro-v1",
  "environment": "LIVE",
  "subject": "64 lowercase hex: HMAC-SHA256(issuer seed, scoped account ID)",
  "state": "64 lowercase hex from the start request",
  "jti": "32 lowercase random hex",
  "issued_at": 0,
  "expires_at": 90
}
```

Время — Unix seconds; максимальный срок 120 секунд, допуск будущего issued_at 30 секунд.
Токен: `sb1.<base64url-json>.<base64url-Ed25519-signature>`, без padding.
У каждого сервиса отдельный seed; касса хранит только публичные issuer-ключи.
Серверная подпись лицензий выполняется в РФ; приватный ключ не передаётся в
Winston/Radar. Существующая закрытая локальная операторская копия не используется
сервисными producer-обработчиками.

## Лицензия

`benefit_grants` и `benefit_devices` отделены от paid orders. Ключ шифруется тем же
закрытым RF cipher, хранится его хеш. Два устройства используют один общий счётчик,
без квот по ОС. Активация/освобождение используют существующие клиентские endpoints.
Сертификат — обычный подписанный `ss1`, без owner-прав и без увеличения срока:
30 дней с обновлением онлайн. Новая сборка клиента для формата не нужна.

`benefits_enabled=false` закрывает новые выдачи, сохраняя ранее выданные активные
лицензии. Отзыв конкретного grant блокирует новые активации/продления; уже выданный
сертификат сохраняет обычный офлайн-период. Начисление не зависит от платного тарифа.
