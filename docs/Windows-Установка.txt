Shift Switcher для Windows

Скачать последнюю сборку: https://vhvost.com/shift-switcher/

1. Извлеките ZIP в постоянную папку, например Документы → Shift Switcher.
2. Откройте ShiftSwitcher.exe. Отдельная установка .NET не нужна.
3. На странице «Обзор» включите автоисправление и автозапуск, если они нужны.
4. Наберите ghbdtn в отдельном документе и дважды нажмите Shift: привет.

Без выделения исправляется последнее слово; с выделением — выбранный текст.
Ещё один двойной Shift отменяет последнее исправление при неизменённом поле.
Ctrl+Alt+Z — отмена. Ctrl+Alt+. — один символ слева от курсора.
Иконка в трее показывает RU/EN. Закрытие настроек оставляет программу в фоне.
Чтобы завершить её, выберите «Выйти» в меню значка.

Это предварительный Windows-выпуск. Его реализованные функции доступны
бесплатно для проверки. Проверены отдельные поля Chrome на Windows x64;
совместимость всех программ и физической клавиатуры ещё не подтверждена.
Автоматика требует русских и английских языковых словарей Windows.
Парольные и неподдерживаемые поля пропускаются. Терминалы и редакторы кода
исключены из автоматики. Замена не использует буфер обмена.

Сборка пока без подписи Authenticode. Сверяйте источник и контрольную сумму;
защиту Windows отключать не нужно.
